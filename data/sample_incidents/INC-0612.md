# INC-0612 — Billing route idempotency key drop

## Summary
`services/api_gateway/routes/billing.py` stopped forwarding `idempotency_key` on create_charge.
Duplicate charges appeared under client retries.

## Impact
- Double charges for ~120 customers
- Manual refunds required

## Root cause
Payload cleanup accidentally removed the key before HttpClient post.

## Fix
Restored key passthrough and added contract test for charge requests.
