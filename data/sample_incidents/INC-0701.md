# INC-0701 — Notify sender webhook fan-out failure

## Summary
`services/notify_service/sender.py` posted to webhook-relay with a truncated payload body after a template render change.
Partners stopped receiving payment_succeeded events.

## Impact
- Missing merchant webhooks for 2 hours
- Support tickets about silent payment confirmations

## Root cause
Sender assumed templates always included `{name}`; new copy path omitted the field and raised mid-delivery for a subset of events.

## Fix
Validated required template fields before HTTP post; added fallback copy; alerted on delivery_failed ratio.

## Lessons
Copy-only seeming changes can still break sender delivery contracts.
