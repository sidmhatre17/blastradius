# INC-1042 — Auth middleware timeout cascade

## Summary
`services/api_gateway/auth/middleware.py` lowered `AUTH_DEADLINE_MS` below auth_service p95.
Bearer introspection calls via the shared client began timing out during peak login traffic.

## Impact
- Elevated 401 rates on `/v1/billing/*`
- Retry storms into `auth_service`
- Customer checkout failures for ~18 minutes

## Root cause
Deadline in auth middleware was tuned without load data. When auth latency spiked, gateway treated slow-but-healthy responses as failures.

## Fix
Restored deadline to 800ms+, added latency histogram alert on auth middleware, and documented that deadline changes require a soak test.

## Lessons
Treat auth middleware timeouts as a blast-radius event across every authenticated route.
