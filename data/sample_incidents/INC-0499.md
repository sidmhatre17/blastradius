# INC-0499 — Revocation check fail-open surprise

## Summary
`services/auth_service/validate.py` fail-open behavior on revocation lookup was undocumented.
Revoked tokens remained accepted when revocation service blipped.

## Impact
- Security exception filed
- Limited window of accepted revoked sessions

## Root cause
Demo-era fail-open left enabled in production config for non-money paths, later reused broadly.

## Fix
Fail-closed for privileged scopes; documented policy in validate module.
