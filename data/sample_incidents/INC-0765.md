# INC-0765 — JWT clock-skew invalid signature wave

## Summary
`services/auth_service/jwt_ops.py` changed claim canonicalization / signing input formatting.
Tokens minted before the change failed `verify_signature` after rolling deploys.

## Impact
- Spike in `bad_signature` from validate_token
- Gateway auth middleware returned 401 for valid sessions

## Root cause
Signing payload serialization became order-sensitive while older tokens used a different JSON separator style.

## Fix
Temporarily accepted both serialization forms; forced token refresh; added compatibility tests in jwt_ops.

## Lessons
JWT helper edits are auth-critical even when they look like pure refactors.
