# INC-0666 — Payments UI currency formatting bug

## Summary
Unrelated frontend issue: checkout displayed amounts with an extra zero for JPY.
No backend services were involved.

## Impact
- Confusing UX for a small % of shoppers
- No availability impact

## Root cause
Locale formatter treated JPY as a 2-decimal currency.

## Fix
Corrected ISO currency fraction digits in the UI package.

## Lessons
Distractor incident for retrieval evaluation — should not rank highly for backend shared-client diffs.
