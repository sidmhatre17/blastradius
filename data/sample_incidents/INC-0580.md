# INC-0580 — Metrics cardinality explosion

## Summary
Labeling changes in `packages/common/metrics.py` included unbounded route paths.
Prometheus memory grew quickly on gateway hosts.

## Impact
- Metrics scrape failures
- No customer-facing outage

## Root cause
High-cardinality labels on REQUESTS counter.

## Fix
Normalized route templates; capped label values.
